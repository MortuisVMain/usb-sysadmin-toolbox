# 003. Интеллектуальный модуль экспресс-диагностики «Доктор ПК» (Human-Readable Health Advisor)

**Статус:** Принято / Реализовано  
**Дата:** 2026-09-09  
**Компоненты:** `Toolbox.ps1` (функция `Invoke-SystemDoctor`)  

---

## 1. Контекст и решаемая проблема

Пользователи и начинающие мастера при диагностике сбоев ПК сталкиваются с непонятными техническими кодами ошибок (например, `0x0000001A`, `WHEA-Logger Event 18`, `Kernel-Power Event 41`, `DISM 0x800f081f`), которые требуют длительного поиска в интернете и не дают ответа на вопрос: **«Что сломалось и какую кнопку нажать для починки?»**.

Цель решения: создать автоматический 6-факторный экспресс-тест, переводящий сигнатуры системных логов и датчиков в понятные рекомендации на простом русском языке с прямыми указаниями на инструменты починки из Toolbox.

---

## 2. Архитектура и алгоритм проверки (6 векторов)

1. **Диски и хранилище:**
   * Проверка свободного места на системном томе `C:`. Порог предупреждения: `< 15 GB`.
   * Запрос WMI класса `root\wmi:MSStorageDriver_FailurePredictStatus`. Если `PredictFailure == True` — флаг критического отказа накопителя (битые сектора, износ флеш-памяти SSD).
2. **Оперативная память (RAM) и утечки:**
   * Запрос текущей свободной физической памяти через `Win32_OperatingSystem`.
   * Фильтрация журнала событий `System` на наличие `Event ID 2004 (Resource-Exhaustion-Detector)` за последние 7 дней. Позволяет выявлять зависания из-за исчерпания памяти без необходимости многочасовых стресс-тестов.
3. **Синие экраны (BSOD) и аппаратные сбои WHEA:**
   * Запрос журнала событий на ошибки `Microsoft-Windows-WHEA-Logger` (аппаратные сбои процессора, шины PCIe, кэша).
   * Подсчет аварийных перезагрузок `Kernel-Power (Event ID 41)`.
   * Анализ `BugCheck (Event ID 1001)` в журнале и сопоставление кодов:
     * `0x0000001A` / `MEMORY_MANAGEMENT` ➔ Неисправность планок RAM или окисление контактов.
     * `0x000000D1` / `0x0000003B` / `0x0000007E` ➔ Сбой видеодрайвера или сетевого драйвера (чистая переустановка через DDU).
     * `0x00000124` ➔ Нестабильность CPU (перегрев, сбой питания).
4. **Целостность компонентов Windows:**
   * Быстрый опрос состояния хранилища компонентов через штатную утилиту `dism.exe /Online /Cleanup-Image /CheckHealth`. Не нагружает процессор и мгновенно сообщает, поврежден ли реестр компонентов.
5. **Батарея и износ (для ноутбуков):**
   * Расчет фактического износа аккумулятора:  
     $$\text{Wear} = \left(1 - \frac{\text{FullChargeCapacity}}{\text{DesignCapacity}}\right) \times 100\%$$
   * Предупреждение выводится только при износе выше 45%.
6. **Сетевой стек и DNS:**
   * Каскадный пинг: Шлюз (роутер) ➔ Интернет IP (`1.1.1.1`) ➔ Резолвинг DNS (`microsoft.com`). Позволяет мгновенно локализовать: сбоит домашний провод/Wi-Fi, авария у провайдера или завис DNS-сервер.

---

## 3. Человеко-ориентированный отчет (Human-Friendly UI)

В конце работы модуль выводит не сухие логи, а структурированную карточку:
* **[КРИТИЧНО] / [ВНИМАНИЕ]** с цветовой кодировкой (красный / желтый).
* **Что не так:** Понятное объяснение сути сбоя.
* **Как починить:** Конкретный пункт меню Toolbox (например, *«Запустите [5]->[4] (SFC + DISM)»* или *«Выполните чистку драйвера через [3]->[5] (DDU)»*).
