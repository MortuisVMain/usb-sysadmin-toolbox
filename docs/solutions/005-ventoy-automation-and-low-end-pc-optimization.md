# 005. Автоматизация Ventoy (Обход проверок Win 11), спасение данных и ускорение слабых ПК

**Статус:** Принято / Реализовано  
**Дата:** 2026-09-09  
**Компоненты:** `ventoy/ventoy.json`, `Toolbox.ps1`  

---

## 1. Контекст и решаемые задачи

При работе на выездах системные администраторы сталкиваются с тремя типичными проблемами:
1. **Жесткие требования Windows 11 при чистой установке:** На компьютерах без TPM 2.0 или с неподдерживаемым процессором/RAM штатный установщик Windows 11 блокирует установку («Этот компьютер не соответствует требованиям к системе»). Также Windows 11 принуждает к входу через аккаунт Microsoft (MSA).
2. **Перегруженное и непонятное меню Ventoy:** Длинные технические имена ISO-файлов (например, `WinPE11_10_8_Sergei_Strelec_x86_x64_2026.07.09_Russian.iso`) неудобны для быстрого выбора.
3. **Нехватка места на диске C: и 100% загрузка старых HDD:** Компьютеры с малыми SSD (64–128 ГБ) часто переполняются файлом гибернации `hiberfil.sys` (занимающим объем всей оперативной памяти), а старые механические жесткие диски зависают из-за постоянной фоновой индексации `WSearch`.

---

## 2. Архитектура реализованных решений

### А. Конфигурационный файл Ventoy (`ventoy/ventoy.json`)
* **Авто-патчинг инсталлятора Windows 11:**
  ```json
  "control": [
      { "VTOY_WIN11_BYPASS_CHECK": "1" },
      { "VTOY_WIN11_BYPASS_NRO": "1" }
  ]
  ```
  `VTOY_WIN11_BYPASS_CHECK` внедряет ключи `BypassTPMCheck`, `BypassSecureBootCheck`, `BypassRAMCheck`, `BypassCPUCheck` в память загрузчика при запуске любого ISO с Windows 11.  
  `VTOY_WIN11_BYPASS_NRO` автоматически обходит требование подключения к сети и создания учетной записи Microsoft (позволяет создать локального пользователя).
* **Словарь алиасов (`menu_alias`):** Подменяет имена файлов на понятные русские названия со значками (например, *🚑 WinPE 11/10 Sergei Strelec*, *🛡️ Kaspersky Rescue Disk*).

### Б. Раздел «Спасение данных и клонирование дисков» (Раздел 6)
* Интеграция профессионального софта с флешки:
  * **DMDE:** Экспресс-восстановление структуры томов MBR/GPT при повреждении таблицы разделов.
  * **R-Studio:** Глубокое сканирование и вытягивание файлов по сигнатурам.
  * **AOMEI Partition Assistant:** Быстрое изменение размера томов и конвертация MBR в GPT без потери данных.
  * **Acronis True Image / AOMEI Backupper:** Клонирование работающей Windows с медленного HDD на новый SSD без переустановки.
  * **HDD Low Level Format Tool:** Низкоуровневая затирка нулями для изоляции сбойных секторов.

### В. Модуль «Ускорение слабых ПК и освобождение места» (Раздел 7)
* **`powercfg -h off`:** Моментально удаляет скрытый системный файл `C:\hiberfil.sys`, высвобождая от 8 до 32 ГБ пространства на системном диске.
* **Отключение `WSearch`:** Полная остановка службы индексации Windows Search, снимающая постоянную 100% нагрузку с магнитных дисков (HDD) на слабых офисных ПК.
* **Ultimate Performance Scheme:** Активация скрытого плана электропитания «Максимальная производительность» через GUID `e9a42b02-d5df-448d-aa00-03f14749eb61`.
* **Сброс кэша значков:** Очистка `IconCache.db` и `thumbcache_*.db` с перезапуском проводника для исправления белых ярлыков на рабочем столе.
