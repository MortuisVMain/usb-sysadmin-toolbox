# 002. Гарантированный запуск с правами Супер-Администратора (High Integrity & SeDebugPrivilege)

**Статус:** Принято / Реализовано  
**Дата:** 2026-09-09  
**Компоненты:** `Toolbox.bat`, `Toolbox.ps1`, `Toolbox.lnk`  

---

## 1. Контекст и ограничения модели безопасности Windows

При создании системных скриптов в среде Windows сисадмины сталкиваются с ограничениями стандартного UAC и токенов безопасности:

1. **Потеря рабочей директории при RunAs:**
   * Когда процесс запускается с повышением прав через `Start-Process -Verb RunAs`, Windows по умолчанию сбрасывает рабочий каталог (`Working Directory`) в `C:\Windows\System32`. В результате любые относительные пути к флешке или `$PSScriptRoot` могут рассчитываться некорректно.
2. **Ограниченный токен Администратора (Filtered Token):**
   * Даже после нажатия "Да" в окне UAC, процесс работает с ограниченными привилегиями. Критические права Win32 — `SeDebugPrivilege` (доступ к памяти и закрытым процессам), `SeTakeOwnershipPrivilege` (захват владения системными файлами) и `SeBackupPrivilege` — по умолчанию отключены (`Disabled`).
3. **Неудобство для пользователя:**
   * Требование открывать контекстное меню и выбирать "Запуск от имени администратора" создает трение и повышает риск ошибок.

---

## 2. Архитектура решения «В 1 клик с иконки»

Реализована 4-уровневая система автоматической элевации:

1. **Ярлык с флагом `SLDF_RUNAS_USER` (`Toolbox.lnk`):**
   * Создан бинарный `.lnk` ярлык с установленным битом `0x20` по смещению `0x15` заголовка Shell Link. 
   * Ярлык снабжен официальным значком системного щита UAC из `imageres.dll,78` и запускает скрипт сразу с запросом максимальных прав.
2. **Железобетонный авто-элеватор в `Toolbox.bat`:**
   * Проверяет наличие прав через команду `net session`.
   * При отсутствии прав перезапускает себя с глаголом `RunAs`, явно передавая рабочий каталог накопителя (`-WorkingDirectory '%SCRIPT_DIR%'`).
3. **Внутренний Guard в `Toolbox.ps1`:**
   * Если пользователь запустил скрипт напрямую в консоли или через проводник без BAT-файла, скрипт анализирует `[Security.Principal.WindowsPrincipal]::IsInRole(Administrator)` и самостоятельно поднимает права.
4. **Token Privilege Booster (C# P/Invoke):**
   * В памяти процесса через Win32 API `OpenProcessToken` и `AdjustTokenPrivileges` принудительно активируются:
     * `SeDebugPrivilege`
     * `SeTakeOwnershipPrivilege`
     * `SeBackupPrivilege`
     * `SeRestorePrivilege`
   * Это снимает ограничения при модификации реестра, разблокировке файлов и управлении службами.

---

## 3. Проверка работоспособности

- При двойном клике на `Toolbox.lnk` или `Toolbox.bat` система запрашивает UAC (если включен) и открывает окно консоли с зеленой плашкой:
  `Права: [ СУПЕР-АДМИНИСТРАТОР (HIGH INTEGRITY / SeDebug) ]`
- Ошибки "Access Denied" при системных фиксах исключены.
