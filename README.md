[![Release: Beta](https://img.shields.io/badge/Release-Beta%20v0.9.0-orange.svg)]()

Универсальный модульный инструмент для системных администраторов, мастеров по ремонту ПК и энтузиастов. Предназначен для работы на мультизагрузочных флешках (**Ventoy** / LiveUSB) или прямо в рабочей среде Windows.

---

## ⚡ Главные особенности

- **Автономность и умный Fallback:** Работает как онлайн (напрямую загружая скрипты и утилиты с GitHub), так и в полном оффлайне с вашей флешки.
- **Поддержка любых версий Windows:** От Windows 7 SP1 до самой свежей Windows 11 24H2/25H2 (а также аварийный CMD-режим для Windows XP).
- **Патчинг протоколов на лету:** Автоматически активирует TLS 1.2 / TLS 1.3 на Windows 7 / 8.1 для поддержки современного защищенного HTTPS.
- **Авто-права Администратора:** Запуск в 1 клик через `Toolbox.bat` без ручного открытия терминала от имени администратора.
- **Независимость от буквы диска:** Все пути рассчитываются динамически (`$PSScriptRoot`), флешка работает под любой буквой (`D:`, `E:`, `H:`, `Z:`).

## 🚀 Установка и использование

1. Скачайте репозиторий или файлы `Toolbox.bat` и `Toolbox.ps1`.
2. Поместите их в корень вашей флешки или в любую удобную папку на диске.
3. Запустите **`Toolbox.bat`** обычным двойным кликом.

---

## 📂 Рекомендуемая структура папок на флешке

```text
USB_Drive:\
│   Toolbox.bat             <-- Лаунчер
│   Toolbox.ps1             <-- Главное меню
│
├───OS\                     <-- Ваши ISO-образы для Ventoy
│       WinPE_Strelec.iso
│       Windows_11.iso
│       Kaspersky_Rescue.iso
│
└───Programs\               <-- Оффлайн-программы
    ├───Activators\         <-- AAct / KMS
    ├───Diagnostic\         <-- AIDA64, OCCT, FurMark, DDU
    ├───SDI\                <-- Snappy Driver Installer
    ├───Zapret\             <-- Загружаемый модуль Zapret
    └───MInst.exe           <-- Оболочка MInstAll / WPI
```
